# Changelog

## 0.1.6

- Replaced retired Visual Studio Marketplace Shields badges with supported static badges.

## 0.1.5

- Added marketplace preview screenshots to show the theme before installation.
- Refined README presentation with Marketplace badges, a clearer feature overview, palette details, installation guidance, and development notes.

## 0.1.4

- Aligned VS Code diff, Git decoration, markdown, and semantic token colors with OpenCode's upstream theme definitions.
- Added overview ruler, minimap gutter, merge editor, and richer markdown/diff token coverage.

## 0.1.3

- Adjusted Git decoration and diff editor colors for clearer added and deleted states.

## 0.1.2

- Improved word highlight opacity so matching symbols remain visible without overpowering the editor.

## 0.1.1

- Replaced the marketplace icon with a square pixel-mark variant closer to OpenCode's logo language.
- Regenerated the icon as an opaque PNG for better Marketplace rendering.

## 0.1.0

- Initial public release of the unofficial OpenCode-inspired VS Code theme.
