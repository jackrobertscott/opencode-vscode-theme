# OpenCode Theme for VS Code

An unofficial VS Code theme inspired by OpenCode's default dark interface.

OpenCode has a distinctive terminal-first look: near-black surfaces, warm peach primary accents, purple keywords, cyan operators and properties, green strings, yellow types, and red variables/errors. This theme brings that palette into VS Code while mapping it across the editor, sidebar, terminal, panels, quick picker, git decorations, and syntax tokens.

![OpenCode Theme icon](images/icon.png)

## Features

- Dark UI based on OpenCode's default `opencode` palette.
- Full editor chrome coverage, including activity bar, sidebar, tabs, panel, status bar, menus, quick input, notifications, and terminal colors.
- Syntax highlighting tuned for TypeScript, JavaScript, JSON, CSS, Markdown, Python, Rust, and other common grammars.
- Semantic token colors for modern language servers.

## Installation

Install from the Visual Studio Marketplace, then select `OpenCode` from `Preferences: Color Theme`.
